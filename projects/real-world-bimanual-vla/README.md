# Real-World Bimanual Robot Learning

This project explores an end-to-end workflow for real-world bimanual robot
learning, spanning operator-guided teleoperation, demonstration collection,
policy inference, and closed-loop execution on a dual-arm platform.

## Project overview

The project focuses on the practical bridge between collecting useful robot
demonstrations and deploying a learned manipulation policy on physical
hardware. The public materials show two representative stages of that loop:

- **Teleoperation:** an operator guides the robot through coordinated dual-arm
  motions used to create task demonstrations.
- **Policy inference:** the robot executes manipulation behavior using a
  learned policy in the real environment.
